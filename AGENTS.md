# Инструкции для Fusion Collection

## Контроль качества и команды разработки

Все команды выполняются из корня `fusion-collection`:

- Запуск приложения из исходников (со сплэш-экраном): `.\run.cmd` (или `uv run python -m fusion_collection`)
- Сборка исполняемого дистрибутива PyInstaller: `.\build.cmd`
- Обязательные проверки качества:
  - `uv run ruff check . --fix`
  - `PYTHONUTF8=1 uv run mypy . --pretty`
  - `uv run vulture`
  - `uv run pytest`

## Архитектурные и аппаратные инварианты

1. **Критическое ограничение безопасности ЦАП `ADAM-4021` (`+0.001 В`):**
   При подаче строгого нуля (`0.000 В`) с модуля `ADAM-4021` на управляющий вход силового блока печи ВТА силовая часть переходит в режим короткого замыкания и выбивает вводные автоматы. Поэтому к любому задаваемому напряжению `ADAM-4021` (включая `0.0 В` при сбросе и остановке нагрева) обязательно прибавляется смещение `SAFE_ZERO_OFFSET_V = 0.001` В. Удалять это смещение категорически запрещено.
2. **Проверка конфигурации модулей (`$AA2`) без молчаливой перезаписи:**
   При несоответствии настроек модулей `ADAM-4011`/`4021` требованиям программы приложение обязано сначала предупредить пользователя с показом полной распарсенной конфигурации и предложить применить требуемую конфигурацию (`%AANNTTCCFF`).
3. **Постоянный мониторинг и предупреждение об обрыве термопары:**
   Опрос модулей и показ живых данных (включая текущие выбранные типы термопар для каждого канала) работают непрерывно с момента подключения к оборудованию, в том числе вне записи измерения. При обрыве термопары (`abs(emf) >= 65.5` мВ) выводится только предупреждение без автоматического отключения нагрева.
4. **Формат сохранения:**
   Все новые измерения (и ВТА, и ДТА) сохраняются в единый контейнер сырых измерений `.fus` через библиотеку `fusion-common`.
